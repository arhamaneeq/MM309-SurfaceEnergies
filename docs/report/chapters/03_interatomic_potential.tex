\section{Interatomic Potential}
\subsection{Potential formalism and source}
The calculations use the modified embedded-atom method (MEAM), a semi-empirical many-body potential that extends the embedded-atom method by including angular contributions to the local atomic environment. This formalism is designed to represent metallic bonding where local coordination and angular character influence energetics \cite{baskes1992meam}. In LAMMPS, the MEAM setup reads elemental reference parameters from a library file and alloy-specific interaction parameters from a separate file; the element order and LAMMPS atom-type mapping must match the intended Fe, Ni, and Al types \cite{lammpsmeam}.

The project files \texttt{library.meam} and \texttt{FeNiAl.meam} correspond to the Fe--Ni--Al MEAM parameterization associated with Sharifi and Wick \cite{sharifi2025meam}. The uploaded paper is the source publication for this potential family. The work develops unary, binary, and ternary interactions for combinations of Cu, Ti, Ni, Cr, Co, Al, Fe, and Mn, using DFT and experimental information for different fitting targets.

\subsection{Suitability for the assigned alloy}
The potential provides a documented, composition-relevant starting point for atomistic simulations of Fe--Ni--Al. The cited parameterization includes the constituent elements and ternary interactions, and its fitting procedure considers structural and energetic properties relevant to metallic alloys \cite{sharifi2025meam}. This provenance supports using the potential for an exploratory surface-energy study, provided the local files and type mapping are checked and the bulk structure and relaxation behaviour are verified. Potential provenance alone does not establish quantitative accuracy for every surface orientation, chemical configuration, or temperature.

\subsection{Validation and limitations}
The potential publication and associated repository documentation caution that this model family was not optimized for temperature-dependent properties and was not fitted to density, thermal expansion, or thermal conductivity data \cite{sharifi2025meam}. This matters for any later interpretation of temperature-dependent simulations. The present project should validate the chosen setup by checking the elemental/type mapping, bulk lattice and energy, convergence of the slab model, and stability of relaxed structures. Surface energies from this potential should be described as model predictions, with the potential's documented limitations acknowledged rather than treated as a universal validation.
