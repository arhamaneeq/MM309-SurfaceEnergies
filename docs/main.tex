% ==================== ABSTRACT ====================
\begin{abstract}
This report documents the atomistic-modelling workflow and preliminary
convergence tests for the Fe--Ni--Al surface-energy project. The production
workflow defines three compositions: equiatomic FeNiAl,
Fe$_{20}$Ni$_{50}$Al$_{30}$, and Fe$_{50}$Ni$_{30}$Al$_{20}$.
The saved convergence dataset uses a separate Fe$_{25}$Ni$_{25}$Al$_{50}$
test composition and is not a production-composition result. For a
controlled FCC (111) slab, the 12- and 14-layer surface-energy estimates
differ by approximately 0.0052 J/m$^2$, while 4 \AA\ of vacuum on each
side matches the 25 \AA\ reference at the reported energy precision.
An atom-type mapping inconsistency between the convergence and production
workflows remains to be resolved before these tests can be treated as
validated evidence for production calculations. Temperature-dependent
production results are not yet reported.
\end{abstract}
